# Silence Dog — Support

Official support and contact page for Silence Dog, by Casaxmore.

- Website: https://casaxmore.github.io/casaxmore-silencedog-support/
- Contact: casaxmore@gmail.com
- GitHub Pages publishes the root of the `master` branch.

## Contents

`index.html` is a responsive static page with Spanish and English copy, a language switch, accessible native FAQ disclosures, and a mailto contact link with an optional support-message template. English is the default, regardless of browser language; `?lang=es` or `?lang=en` provides a direct locale link. No contact form backend, analytics, cookies, external fonts, or third-party scripts are used.

`icono.jpg` is the existing app icon. `app-ads.txt` contains the authorized advertising seller record and must be preserved when updating the page.

## Local preview

Run `python3 -m http.server 8080` from this directory and open http://localhost:8080/.

This repository is independent from the SilenceDog iOS application repository.

## Support privacy

`privacy.html` contains the English and Spanish support-website privacy notice. The contact card gives a short first-layer notice and links to the full notice; the footer links to it too. The notice identifies José Manuel Casabona, operating as Casaxmore, and describes email support and GitHub Pages hosting. It does not replace the iOS app’s separate privacy policy. No consent banner, tracking or new data collection was introduced. Retention and rights commitments in the notice must be followed when handling support mail.
